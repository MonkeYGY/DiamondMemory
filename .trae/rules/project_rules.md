# 钻石记忆系统 - 项目全局规则

## 版本优化流程

### 版本优化启动
1. 用户明确说"开始版本优化VX.Y"或"开始版本VX.Y优化"时，新建版本优化文档 `版本优化记录/版本优化X.Y.md` 到项目根目录下的版本优化记录文件夹中
2. 文档包含：版本号、优化项列表、每项的状态跟踪
3. 告知用户准备就绪后等待具体优化需求

### 版本优化进行中
1. 每项优化完成后立即更新版本优化文档中的状态
2. 所有代码变更遵循项目编码规范
3. 每项优化需验证构建通过

### 版本优化自动记录（全局规则）
1. **每次任务完成后自动触发**：完成任何开发任务后，必须自动查找 `版本优化记录/` 文件夹下当前版本的版本优化文档（格式：`版本优化*.md`）
2. **文档结构强约束（任何时间任何任务适用）**：
   - **任务总览表必须放在文档最上方**（紧跟标题/说明之后）
   - **任务记录按最新时间从上到下排列**（时间倒序）
   - **每次更新必须同步更新任务总览表中的状态**，确保总览表与任务记录一致
   - **状态展示统一带图标（任何时间任何任务适用）**：
     - 待开始：`⏳ 待开始`
     - 进行中：`🚧 进行中`
     - 已完成：`✅ 已完成`
     - 阻塞：`⛔ 阻塞`
     - 取消：`🗑️ 取消`
3. **增量更新**：将本次任务的完成内容追加到“任务记录”顶部，包含：
   - 任务类型（新增/修复/优化/重构/测试）
   - 任务简述
   - 修改文件列表
   - 完成状态
4. **文档不存在时创建**：如果当前版本优化文档不存在，自动创建后更新
5. **保持文档结构清晰**：每个任务记录独立成块，按时间倒序排列

### 版本优化结束
1. 用户说"本次版本优化结束"时，完成以下收尾工作：
   - 更新版本优化文档，标记所有项为已完成
   - 写入完整的优化总结
   - **自动备份一次“完整项目”到项目根目录 `项目备份/` 下**
   - 提醒用户点击侧边栏"💾 备份"按钮进行一键备份
2. 备份路径：
   - **项目内备份（统一规则，适用于任何时间任何项目任何任务）**：`项目备份/`
   - 桌面备份（可选/旧规则）：`/Users/gengyun/Desktop/钻石记忆系统/`
3. 备份格式（推荐）：
   - `Project-backup-YYYY-MM-DDTHH-MM-SS.zip`（推荐，体积更可控）
   - 或 `Project-backup-YYYY-MM-DDTHH-MM-SS/`
4. 备份内容要求：备份“完整项目源码与配置”，可排除体积过大的可再生目录（如 `node_modules/`、`frontend/dist/`、`dist/`、`backend/venv/`、`__pycache__/`）。
5. 最多保留10个历史备份（超出则自动清理最旧备份）

## 技术栈
- 前端：Electron + Vue3 + TypeScript
- 后端：Python/FastAPI (Nuitka编译)
- 模型：Ollama (内嵌) + bge-m3 + qwen系列

## 项目结构
- `frontend/` - Electron前端
- `backend/` - Python后端
- `版本优化记录/版本优化X.Y.md` - 版本优化记录文档
- `PROJECT_OPERATIONS.md` - 项目操作记录

## 编码规范
- 禁止硬编码，所有配置从配置层读取
- 分层架构：表现层/业务逻辑层/数据模型层
- 组件复用，禁止重复造轮子
- 代码无冗余注释

## 协作方式规范
- 用户提出需求后，正常情况下由 AI 直接连续完成并交付最终成品，减少中途反复询问选择
- 除非存在非常重要的高风险操作（如删除文件、不可逆修改、可能影响现有数据或环境安全的操作），否则不要中途打断用户确认
- 需要用户手动配合的步骤，仍需在任务完成后的总结中明确告知

## 任务总结规范
- 每次执行完任务后必须用中文回答总结内容
