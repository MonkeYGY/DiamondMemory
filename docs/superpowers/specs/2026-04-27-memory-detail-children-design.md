# L3/L5 详情页下层条目展示设计

## 背景

记忆管理页的详情弹窗当前只展示被点击记录自身的内容。对于目录型层级 `L3` 和 `L5`，用户还需要在详情页中看到该分类下包含的所有下层内容名称，并能够继续点开对应的 `L4` 或 `L6` 详情。

## 目标

- 在 `L3` 详情页展示同分类下全部 `L4` 记录名称
- 在 `L5` 详情页展示同分类下全部 `L6` 记录名称
- 列表项支持点击，点击后直接切换到对应 `L4` 或 `L6` 详情
- 不改动后端接口，复用前端已加载的记忆列表数据

## 方案

### 数据来源

- 基于 `MemoryView.vue` 中已加载的 `memories`
- 选中项为 `L3` 时，按 `layer === 4` 且 `category` 与当前记录一致进行聚合
- 选中项为 `L5` 时，按 `layer === 6` 且 `category` 与当前记录一致进行聚合
- 排除当前选中项自身，避免异常重复

### 展示方式

- 在现有详情正文下方新增“分类下内容”区块
- `L3` 使用文案“该分类下的 L4 内容”
- `L5` 使用文案“该分类下的 L6 内容”
- 每条项目显示名称，名称复用当前标题提取逻辑；若无显式标题则回退到内容摘要

### 交互

- 子项名称列表为按钮样式
- 点击子项后，将 `selectedMemory` 切换为目标记忆
- 保持在当前弹窗内完成跳转，不新增新弹窗

## 边界处理

- 当前记录没有 `category` 时，区块显示“暂无对应内容”
- 当前分类下没有匹配的下层记录时，区块显示“暂无对应内容”
- 非 `L3` 与 `L5` 详情页不展示该区块

## 影响范围

- 修改 `frontend/src/renderer/views/MemoryView.vue`
- 不涉及后端接口、数据库结构和导出逻辑

## 验证

- 打开 `L3` 详情，确认出现同分类 `L4` 名称列表
- 打开 `L5` 详情，确认出现同分类 `L6` 名称列表
- 点击列表项后，确认弹窗切换到对应详情
- 无匹配内容时，确认显示空状态文案
