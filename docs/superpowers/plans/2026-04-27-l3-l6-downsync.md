# L3-L6 Downsync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make L3-L6 memories downsync in real time into the knowledge base folders, rebuild historical exports once, and treat storage-path switching as a controlled backend restart that does not show the global disconnect modal.

**Architecture:** Extend the existing backend export service into a single downsync coordinator, then wire every L3-L6 lifecycle path through it. Reuse `memory_id + file_sync_info` to avoid upsync/downsync feedback loops, and keep the frontend in a controlled "storagePathChanging" state so backend restarts triggered by path switching are hidden behind a lightweight hint instead of the disconnect overlay.

**Tech Stack:** Python, FastAPI, SQLiteStore, Electron, Vue 3, TypeScript

```ts
async function handleSelectStoragePath() {
  const p = await window.electronAPI?.selectDirectory()
  if (!p) return

  storagePathChanging.value = true
  setBackendRestarting(true)
  setStoragePathChanging(true)

  try {
    if (window.electronAPI?.setStoragePath) await window.electronAPI.setStoragePath(p)
    if (window.electronAPI?.initStorageDir) await window.electronAPI.initStorageDir(p)
    storagePath.value = p
    toast.success('存储路径已更新，正在后台重启核心服务...')
    await restartBackend(p)
    await waitForBackendRunning()
    await rebuildKnowledgeMemoryExports()
    await refreshStatus()
    await loadStoragePath()
    toast.success('核心服务已重启，新存储路径已生效')
  } catch (error: any) {
    toast.error('切换存储路径失败: ' + error.message)
  } finally {
    storagePathChanging.value = false
    setBackendRestarting(false)
    setStoragePathChanging(false)
  }
}
```
