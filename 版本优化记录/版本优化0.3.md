# 钻石记忆系统 V0.3 版本优化记录

## 架构重构 (Electron + Vue3)
- 放弃原 SwiftUI + Python 的松散架构，采用 Electron + Vue3 作为跨平台桌面应用方案。
- 使用 Nuitka 将 FastAPI 后端编译为独立的黑盒二进制文件，实现跨平台运行和源代码保护。
- 彻底解决依赖问题：用户安装 `.dmg` 后不再需要配置 Python 环境或安装 Node.js，真正实现“开箱即用”。

## Bug 修复与体验优化
- **大模型预加载常驻**：解决启动时大模型无法驻留内存的问题，增加后端 `startup_event` 异步预加载逻辑，确保应用启动后自动拉起 Ollama 并唤醒主 LLM 模型与 `bge-m3` 模型，通过设置 `keep_alive=-1` 保持常驻内存。
- **后端启动与通信**：修复打包后因 Uvicorn 入口引用错误导致的崩溃问题；加入 `8000` 端口直连轮询 fallback，解决 Preload 注入延迟导致的“服务已断开”误报问题。
- **IPC 桥接修复**：修复 Electron `contextBridge` 与 Node ESM 的模块加载冲突，使“设置存储路径”按钮和相关对话框正常唤起。
- **UI 深度还原**：重新设计前端 Vue/CSS 布局，1:1 复刻原版 SwiftUI 的侧边栏、卡片渐变、阴影光效和模型状态指示灯。
- **模型页面交互优化**：本地模型与云端模型切换不再强制立即保存，而是提供专门的“保存并切换”按钮，提升配置体验。

## DM开发辅助工具集成更新
- 更新了 `check_services.sh` 脚本，修复了因进程 ID 获取方式导致的 `ps` 命令非法参数报错。
- 重写了 `create_dmg.sh` 脚本，自动调用 Nuitka 编译后端与 Electron Builder 打包前端，一键在桌面生成免环境依赖的 `.dmg` 安装包。
- 新增 `create_exe.bat` 脚本，允许在 Windows 系统下直接双击打包生成 Windows 专属的 `.exe` 跨平台安装文件。
- **(紧急修复) macOS 桌面端工具打包脚本崩溃退出码 1237 问题**：之前因为注入 `source ~/.zshrc` 时，遇到不兼容的 Bash 语法导致 `set -e` 脚本静默崩溃退出。现已移除该命令并手动补全了 NVM、Node.js 与 Homebrew 等底层环境变量，彻底解决一键打包闪退问题。
- **清理遗留架构代码**：彻底删除了原版基于 SwiftUI 编写的 `.xcodeproj` 工程文件及相关的 Swift UI 代码目录（包括 `DiamondMemory` 主目录和 `DM开发辅助` 原生的 Xcode 工程），现在项目是一个纯净的 Electron + Vue3 + Python 跨平台工程。
