# 记忆同步机制

---

📊 等级: T3 | 📁 L6 技能记忆 | ✅ 已处理



> 📅 创建时间: 2026-04-26 14:52:37

---

技能名称：记忆同步自动化
目标任务：确保钻石记忆系统所有对话记录完整写入数据库
触发条件：系统检测到记忆数据库为空或记录数低于阈值时，或检测到后端服务未运行（端口 8000 无监听）
步骤：
1. 检查后端服务运行状态（端口 8000 监听）
2. 若服务未运行则启动服务
3. 通过 HTTP API（/api/memory/create 端点）调用创建记忆接口
4. 调用前检查当前对话记录状态
5. 生成记忆健康检查报告
6. 若发现数据库为空，执行记忆补全操作
工具：cron 任务调度器、HTTP API 客户端、端口监听检测工具
最佳实践：建议每 6 小时执行一次记忆补全检查，确保对话记录完整性
依赖子技能：后端服务启动、HTTP 请求发送、数据库状态检查
注意事项：需定期执行记忆补全检查，避免 API 调用遗漏导致记忆缺失
